Game Quest 🎮
Game Quest is a simple web application where users can explore a collection of my favorite games. Each game includes a title, image, and description. Visitors can also suggest new games using a form.


📌 About the Project
This project was created as part of my software engineering learning journey. It helped me practice using HTML, CSS, and JavaScript to build a fully functional, interactive website.


🚀 Features
🖼️ Game gallery with images and titles


🔍 Click on a game to view detailed information


📝 Form to suggest new games


📱 Responsive design for all screen sizes


🧠 JavaScript-powered interactivity
